# CEP Task System

This directory contains scoped task briefs for human and AI contributors.

## How to work on a task

1. Find an ID in [TASKS.md](../TASKS.md).
2. Read its full brief and dependencies.
3. Check the repository's open issues and pull requests for active work.
4. Comment with the subtask you intend to take and your proposed deliverable.
5. Create a branch from the current default branch.
6. Submit a pull request that links the task ID and describes evidence, methods, limitations and safety implications.

## Task brief requirements

Each task should state:
- objective and research question;
- context and explicit non-goals;
- scope and subtasks;
- deliverables and file paths;
- evidence/method requirements;
- risks and safeguards;
- dependencies;
- acceptance criteria;
- open questions.

Task completion means a deliverable has passed repository review. It does not establish community consensus, political legitimacy or approval by affected populations.
